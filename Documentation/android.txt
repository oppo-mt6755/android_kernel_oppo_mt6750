1. Android
==========

Android (www.android.com) is an open source operating system for mobile devices.
This document describes configurations needed to run the Android framework on
top of the Linux kernel.

To see a working defconfig look at msm_defconfig or goldfish_defconfig
which can be found at http://android.git.kernel.org in kernel/common.git
and kernel/msm.git

LineageOS 17.1 IPC and emulated storage update
-------------------------------------------
Binder and sdcardfs are imported from:
https://github.com/acroreiser/android_kernel_lenovo_a6010
branch lineage-17.1, commit f7d8195672d653c66eff51066123f46977100f86.

The OPPO hardware drivers and configuration remain in use. Binder keeps its
native ARM64 and compat 64-bit wire ABI, local scheduler priority definitions,
and diagnostic errors. The sdcardfs import retains lower-file fsnotify_open;
the unused d_canonical_path callback is omitted because this VFS lacks it.
The unshared_obb flag is initialized explicitly and shown in mount options.

free_vfsmnt owns per-mount data and the mount ID. Failed mount and clone paths
must not release either resource a second time. Android 10 probing a mount
with unshared_obb exposed this double free and caused a SLUB panic.

Device validation: invalid sdcardfs options return errors safely, per-user and
legacy shared OBB layouts work, bind/remount and read/write pass. Native and
compat Binder ABI8 open/mmap/looper/close probes pass on all three device nodes.

Android 10 threaded /proc/self/fd access
--------------------------------------
Backport upstream 54708d2858e79a2bdda10bf8a20c80eb96c20613 (proc: actually
make proc_fd_permission() thread-friendly). Ambient/file capabilities can
make /proc/<pid>/fd root-owned. Check the caller's thread group rather than
only its thread ID, so SurfaceFlinger worker threads can resolve their own
open library descriptors. Other processes retain the normal access checks.
